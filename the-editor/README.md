# The Editor - 텍스트 로그라이크 어드벤처 게임

## 게임 소개

"The Editor"는 텍스트가 곧 물리 법칙인 세계를 배경으로 한 로그라이크 어드벤처 게임입니다. 플레이어는 에디터(Editor)가 되어 단어를 채굴하고, 문장을 조합하여 전투하고, 이야기의 결말을 짓는 역할을 합니다.

## 실행 방법

### 방법 1: 로컬 서버 실행 (권장)
```bash
cd the-editor
python3 -m http.server 8000
```

브라우저에서 접속:
```
http://localhost:8000
```

### 방법 2: 직접 파일 열기
`index.html` 파일을 브라우저에서 직접 열 수 있습니다. (일부 기능 제한 가능)

## 게임 플레이 가이드

### 1. 시작 화면
- "시작하기" 버튼을 클릭하여 게임을 시작합니다.

### 2. 인트로 및 튜토리얼
- 게임의 배경과 조작법을 읽습니다.
- 타자기 효과로 텍스트가 한 글자씩 나타납니다.

### 3. 챕터 1: 명사의 숲
- **목표**: 상황 텍스트에서 대괄호 [ ] 안의 단어를 클릭하여 수집
- **수집 가능 단어**: 안개, 나무, 돌, 나
- **전투**: 형체 없는 그림자와 전투
  - 주어(명사) + 동사 조합으로 공격
  - 예: "나 + 찌르다" = 공격

### 4. 챕터 2: 동사의 탑
- **목표**: 동사 단어를 수집하고 전투에 활용
- **수집 가능 단어**: 찌르다, 추격하다, 막다, 부수다, 달리다
- **전투**: 검열관과 전투
  - 더 강력한 조합 필요
  - 예: "나무 + 부수다 + 거대한" = 강력한 공격

### 5. 챕터 3: 형용사의 바다
- **목표**: 퍼즐 해결
- **퍼즐**: "파도가 [거칠게] 몰아친다"
  - [거칠게]를 다른 단어로 교체
  - 해결책: 잠잠하게, 얼어붙은, 따뜻하게 중 선택

### 6. 엔딩 크래프팅
- 모은 형용사 단어 중 3개를 선택
- 문장 완성: "세상은 ____ 하고, 사람들은 ____ 하며, 이야기는 ____ 끝났다."
- 선택한 단어의 속성에 따라 엔딩이 결정됩니다:
  - **Happy Ending**: 긍정적인 단어들 (점수 3 이상)
  - **Sad Ending**: 부정적인 단어들 (점수 -2 이하)
  - **Abstract Ending**: 중립적인 단어들 (기본)

## 게임 시스템

### 단어 태그 시스템
각 단어는 고유한 태그를 가지고 있습니다:
- **명사 (Noun)**: 주어로 사용, 원소 속성 보유
- **동사 (Verb)**: 액션 타입 (공격/방어/회피)
- **형용사 (Adjective)**: 분위기/원소 속성, 엔딩 점수에 영향

### 전투 시스템
- **조합**: 주어 + 동사 + (선택) 수식어
- **잉크 시스템**: 마나 대신 잉크 사용, 턴마다 회복
- **데미지 계산**: 태그 조합에 따라 데미지/방어력 결정
- **손패 시스템**: 덱에서 무작위로 5-7개 단어가 손패로 제공

### 애니메이션 효과
- **타자기 효과**: 텍스트가 한 글자씩 나타남
- **단어 추출**: 단어 클릭 시 페이지에서 뜯겨나가는 효과
- **백지화 효과**: 피격 시 화면이 하얗게 점멸

## 기술 스택

- **순수 JavaScript**: React 없이 바닐라 JS로 구현
- **CSS3**: 모던 CSS와 애니메이션
- **HTML5**: 시맨틱 마크업

## 커스터마이징

### 새로운 챕터 추가
`game.js`의 `CHAPTERS` 배열에 새 객체를 추가하세요.

### 단어 태그 수정
`WORD_TAGS` 객체에서 단어의 속성을 수정할 수 있습니다.

### 엔딩 템플릿 변경
`ENDING_TEMPLATES` 객체에서 엔딩 텍스트를 수정할 수 있습니다.

## 문제 해결

### 게임이 로드되지 않는 경우
- 브라우저 콘솔(F12)에서 오류 확인
- 로컬 서버를 사용하여 실행 (CORS 문제 방지)
- 최신 브라우저 사용 권장

### 애니메이션이 작동하지 않는 경우
- 최신 브라우저 사용 권장 (Chrome, Firefox, Edge)
- JavaScript 활성화 확인

### 게임이 진행되지 않는 경우
- 브라우저 콘솔(F12)에서 오류 확인
- 페이지 새로고침
- 게임 상태 확인 (덱에 단어가 있는지 등)
